# 模拟 iCost 小程序

基于需求文档实现的“模拟 iCost”记账小程序，支持多账本、账单录入、图标管理、资产展示与多维统计，适合演示记账产品的整体交互流程。

## 功能概览

- **首页概览**：展示用户资产、当前账本预算执行、待报销金额以及快捷统计。
- **注册/登录**：登录页即首页，未登录用户会被拦截至该页；支持注册新账号或使用默认体验账号 `demo / 123456`。
- **账本管理**：新增/编辑/删除多账本，实时查看每本账本的月度支出、收入与预算剩余。
- **账单录入**：支持支出/收入/转账类型，包含类别、支付方式、时间、报销状态、流转类型等字段。
- **图标管理**：对收入/支出/转账分类图标进行维护，满足个性化需求。
- **资产总览**：展示净资产、总资产/负债、借入/借出，提供隐藏/展示和快速调整功能。
- **统计分析**：按周/月/年/全部/自定义范围统计收支、报销、流转、分类占比与账本对比。

## 目录结构

```
miniprogram/
  pages/
    dashboard/      # 首页概览
    ledger/         # 账本维护
    bill-form/      # 账单录入
    statistics/     # 多维统计
    assets/         # 资产中心
    icon-manager/   # 图标分类维护
  services/
    dataService.js  # 本地状态管理与统计逻辑
  utils/
    format.js       # 金额与日期格式化
```

## 本地运行

1. 使用微信开发者工具打开本项目目录 `D:\WeChatProjects\i-cost`。
2. 运行后默认停留在“账号登录”页，先登录（或注册）再进入其他页面。
3. 确保基础库 ≥ 2.27，支持自定义 tabBar 与新版组件。
4. 如需启用云开发，可在 `app.js` 中配置 `env`，本示例默认走本地存储。

## 数据说明

- `services/dataService.js` 内置演示数据，并通过 `wx.getStorageSync`/`wx.setStorageSync` 持久化。
- 登录体验账号：`demo / 123456`，也可在注册页创建新账号。退出或切换账号时，从首页点击“切换账户 / 注册”跳转到登录页。
- 可在账单录入页不断添加新记录，统计页和资产页会实时联动。
- 如需接入真实后端，可将数据服务替换为云函数/HTTP 请求，但保持接口返回结构即可复用页面。

## 后续拓展建议

- 将 `dataService` 按接口拆分，接入云数据库或企业自建 API。
- 为账单录入增加附件（发票、图片）与 OCR 自动填充能力。
- 在统计页补充图表展示（柱状/环形），提升可视化效果。
- 增加成员/角色与账本共享逻辑，满足多人协作记账场景。
